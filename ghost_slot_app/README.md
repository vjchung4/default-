# Ghost Slot AI (해커톤 데모)

여객열차 운행 사이에 비는 '유휴 선로 시간(Ghost Slot)'을 탐지하고, 대기 중인 화물열차와 매칭해
관제사가 원클릭으로 승인하는 흐름을 재현한 Streamlit 데모입니다.

모든 열차 스케줄/화물 데이터는 시연을 위한 시뮬레이션이며, 실제 코레일 운행 데이터가 아닙니다.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 화면 구성

- **관제 대시보드**: 여객열차 스케줄 타임라인 + AI가 탐지한 유휴 슬롯, 대기 중인 화물열차 목록
- **AI 추천 & 원클릭 승인**: 슬롯-화물열차 매칭 추천과 승인 버튼
- **현장 알림 로그**: 승인 시 기관사/화물역 앱으로 나가는 알림을 시뮬레이션
