# 철도 운임 상수 보정 (팀원 앱 반영용 참고 파일)

이 폴더는 팀원(`syj4813/Freight`)이 만든 철도/도로 운임 계산 코드를
**그대로 복사**해온 것입니다 — 이 저장소(default-)의 앱이 아니라, 팀원
저장소에 실제로 반영해 달라고 전달하기 위한 참고용입니다.

## 무엇을 바꿨나

`rail_freight_nodes.py`의 `RAIL_TON_KM_RATE_WON` 상수를 `55` → `91`
(원/톤·km)로 수정했습니다.

## 왜 바꿨나

코레일에 실제 운임 데이터를 요청했으나 "정상운임(공시운임)을 참고하라"는
답변을 받았고, 아직 공식 임률표를 확보하지 못한 상태입니다. 기존 `55원`은
근거가 약한 잠정값이었고("도로 대비 1/3~1/2 수준"이라는 출처 불명확한
가정), 실제로 이 값으로 계산하면 모든 거리에서 철도가 도로보다
비현실적으로 압도적으로 저렴하게 나오는 문제가 있었습니다.

한국교통연구원(KOTI) 연구에 따르면 철도는 대략 **300km 이상 구간부터
도로 대비 비용 우위**를 갖는다는 정성적 결과가 있어, 이 손익분기점에서
`road_cost.py`의 트럭 요금(20ft 컨테이너 실중량 약 18톤 기준)과 철도
요금이 같아지도록 역산해 `91원/톤·km`을 얻었습니다.

## 한계

이것도 여전히 **실제 공시운임표가 아니라 역산 추정치**입니다. 코레일
공식 화물운송약관/임률표를 확보하는 대로 이 값을 교체해야 합니다.

## 반영 방법 (팀원분이 직접)

본인 저장소의 `rail_freight_nodes.py`에서 `RAIL_TON_KM_RATE_WON` 값과
주변 주석을 이 파일 내용으로 교체하시면 됩니다.
